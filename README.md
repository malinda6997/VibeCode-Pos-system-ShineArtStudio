## 🌟 Overview

Shine Art Studio POS is a comprehensive, **fully offline** point-of-sale and business management system specifically designed for photography studios. This enterprise-grade application handles everything from customer management and billing to bookings, inventory tracking, and advanced financial reporting.

### ✨ Key Highlights

- 🤖 **100% AI-Powered Development** - Entire codebase generated using GitHub Copilot
- 🔒 **Fully Offline** - No internet connection required after installation
- 🎨 **Modern Dark UI** - Professional dark theme with intuitive design
- 📊 **Advanced Analytics** - Executive and industrial reports with insights
- 🖨️ **Professional PDFs** - High-quality bills, invoices, and reports
- 👥 **Role-Based Access** - Admin and Staff permission management
- 💼 **Production Ready** - Battle-tested with real photography studio workflows

## 🚀 Installation

### Prerequisites


## 📦 Building Executable

To create a standalone .exe file:

```bash
# Install PyInstaller
pip install pyinstaller

# Build executable (included in project)
.\BUILD_EXE.bat

# Or manually
pyinstaller --onefile --windowed --icon=assets/icons/app_icon.ico main.py
```

Executable will be created in `dist/` folder.

## 🐛 Troubleshooting

### Database Issues
- Delete `pos_database.db` to reset (backup first!)
- Check file permissions
- Ensure SQLite is installed

### PDF Generation Problems
- Install ReportLab: `pip install reportlab`
- Check write permissions for `bills/` and `invoices/` folders
- Verify fonts are available

### UI Display Issues
- Update CustomTkinter: `pip install --upgrade customtkinter`
- Check screen resolution compatibility
- Try different appearance themes
